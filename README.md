# Allghelierce Ecoshift

## How do I install these formulae?

`brew install allghelierce/ecoshift/<formula>`

Or `brew tap allghelierce/ecoshift` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "allghelierce/ecoshift"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
